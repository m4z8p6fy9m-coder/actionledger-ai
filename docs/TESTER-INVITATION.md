# Invitation to independently test ActionLedger

Copy and share this invitation with developers you know or in a community that permits such requests. No invitation has been sent by adding this file.

> I'm looking for independent developers to test ActionLedger AI, an experimental local reliability layer for agent actions. The exercise simulates a payment succeeding immediately before an agent worker crashes. I'd appreciate an honest report of what worked, what failed, what was skipped, and which parts of the setup were confusing.
>
> Start here: [reproduction checklist](https://github.com/m4z8p6fy9m-coder/actionledger-ai/blob/main/docs/INDEPENDENT-REPRODUCTION.md). Node.js 24+ and pnpm 11.25.0 are required; after installing dependencies the crash demonstration uses local simulated services, without an API key. PostgreSQL testing is optional.
>
> Please open an [independent reproduction report](https://github.com/m4z8p6fy9m-coder/actionledger-ai/issues/new?template=independent-reproduction.md) with your revision, OS, commands and actual results. Do not include credentials or private data. You do not need to report a successful result; failures and skipped checks are equally useful.

Maintainers: request consent before quoting a tester or publishing identifying details, link to their original report, and distinguish independently verified observations from project-authored evidence. Do not characterize this as a security audit or general production certification.
